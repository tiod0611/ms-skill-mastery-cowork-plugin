# ms-skill-mastery-cowork-plugin

Copilot Cowork 플러그인 트레이닝/데모 모음 저장소입니다. 각 데모는 최상위 폴더 하나에 독립된 플러그인(매니페스트 + 스킬 + 커넥터)으로 담기며, 이 저장소는 향후 여러 데모 플러그인을 함께 호스팅할 수 있도록 구성되어 있습니다.

## 수록된 플러그인

### [`ms-skill-mastery/`](./ms-skill-mastery)

사용자가 마스터하고 싶은 기술(예: React, Azure Kubernetes Service)을 말하면, Microsoft Learn MCP 서버로 리서치하여 단계별 학습 로드맵을 만들고, 이를 항상 동일한 디자인의 HTML 페이지로 렌더링해 주는 교육용 데모 플러그인입니다. 자세한 내용은 [`ms-skill-mastery/README.md`](./ms-skill-mastery/README.md)를 참고하세요.
